# Student Portal Site

A responsive student portal dashboard with multiple pages for:

- Overview dashboard
- Course tracking
- Assignment management
- Grades and performance
- Calendar and academic resources

## Run locally

From the project folder, start a local web server:

```bash
cd /workspaces/student-portal-site
python3 -m http.server 3000
```

Then open:

```text
http://localhost:3000/index.html
```

The site includes additional pages such as:

- courses.html
- assignments.html
- grades.html
- calendar.html
- resources.html
